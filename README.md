# MYDAF · 로컬 네이버 블로그 자동 포스팅

내 PC에서만 돌아가는 네이버 블로그 자동 작성·발행 프로그램입니다.
회원가입, 이용권, 강제 업데이트, 사용 기록 전송이 없습니다.

## 하는 일 (원클릭으로 계속 반복)

1. **주제 발굴**: 내 키워드 목록(개수·길이 제한 없음) + 구글 트렌드(한국)
2. **자료 수집**: 네이버 뉴스, 구글 뉴스·검색, 내 RSS, KISS 학술논문(초록), 학회 RSS/게시판
3. **사실 검증(필수)**: AI가 뽑은 사실마다 원문 인용문을 붙이고, 프로그램이 그 인용문이 실제 원문에 있는지 대조합니다. 서로 다른 매체 2곳 이상에서 확인된 사실만 씁니다. 기준에 못 미치면 그 주제는 발행하지 않습니다.
4. **AI 작성**: 검증된 사실만 근거로 AI가 글을 씁니다. **Google Gemini(무료 키)** 또는 Claude(유료) 중 선택. 근거 없는 문단은 프로그램이 빼버립니다.
5. **추론 기록**: 추론·추리한 문단은 "어떤 사실에서 어떤 논리로"를 반드시 남겨 PC 로그에 저장합니다.
6. **출처 표기**: 글 맨 아래 우측(설정으로 좌측)에 작은 글씨(11)로 매체·제목·날짜·주소.
7. **이미지 자동 준비**: 소제목마다 자유 라이선스 사진(Pexels 키가 있으면 Pexels, 없으면 위키미디어 공용)을 찾아 넣고, 작가·라이선스를 출처란에 자동 표기. 뉴스 사진은 저작권 때문에 쓰지 않습니다.
8. **네이버 발행**: 이 PC의 Edge/Chrome으로 스마트에디터에 작성(소제목은 인용구, 기본 글자 크기 소제목 34 · 본문 30) 후 임시저장 또는 발행.
9. 다음 글까지 넉넉히 쉬고(아래 안전장치), 하루 3개를 채우면 다음 날 아침까지 쉽니다.

## 품질과 안전장치

- **고품질 작성**: AI가 깊게 생각하는 설정(xhigh)으로 초안을 쓰고, 편집장 역할로 한 번 더 검토·수정합니다. 검증된 사실이 6개 미만이거나 본문이 1,800자 미만이면 올리지 않습니다.
- **하루 최대 3개 (고정)**: 설정 화면, '한 편만 실행', 원격 명령 어떤 경로로도 3개를 넘길 수 없습니다. 네이버 에디터까지 갔다가 실패한 시도도 1개로 셉니다.
- **간격**: 직전 글로부터 최소 3시간, 기본 200~300분 사이 랜덤.
- **시간대**: 기본 오전 8시~오후 10시 사이에만 올립니다.
- 기준에 막히면 AI를 부르기 전에 멈추므로 비용도 들지 않습니다.

## 설치·실행

1. GitHub의 **Actions → 최신 빌드 → MYDAF-windows** 에서 `MYDAF.exe` 를 받아 한 번 실행합니다. 처음 실행할 때 바탕화면에 **MYDAF 아이콘**이 자동으로 생기고, 이후에는 그 아이콘으로 실행하면 됩니다 (프로그램은 `%LOCALAPPDATA%\Programs\MYDAF` 에 복사됨). 아이콘이 지워지면 실행 탭의 "바탕화면 아이콘 만들기"를 누르세요.
2. 처음 실행하면 **"처음 한 번만 설정해요"** 화면이 나옵니다: Claude API 키, 블로그 ID(`tudulyee33` 기본), 키워드, 네이버 로그인.
3. 홈 화면 오른쪽 아래 **▶ 자동 등록 시작** 을 누르면 끝. 진행 상황(단계·진행률·타임라인)이 홈에 실시간으로 보입니다.
4. 작가 스타일, 글자 크기, 소제목 모양, 이미지는 **글쓰기 설정** 에서 바꿀 수 있습니다.

처음에는 발행 방식을 `draft`(임시저장)로 두고 결과를 확인한 뒤 `publish` 로 바꾸길 권합니다.

## 저장 위치 (`%APPDATA%\MYDAF`)

| 파일 | 내용 |
|---|---|
| `config.json` | 설정 (API 키 포함, 이 PC에만) |
| `logs/app.log` | 진행 기록 |
| `logs/reasoning.jsonl` | **추론·추리 기록** (글별) |
| `posts/<날짜_주제>/` | 수집 자료, 검증표, 원고, 검사 결과, 미리보기, 에디터 화면 캡처 |
| `history.jsonl` | 발행 이력 (주제 중복 방지) |
| `browser-profile/` | 네이버 로그인 쿠키 (비밀번호는 저장하지 않음) |

## Gemini 무료로 쓰기

1. aistudio.google.com 에 구글 계정으로 로그인 → **Get API key** → 키 만들기
2. 처음 설정 화면 1단계에서 **Google Gemini (무료)** 를 고르고 키를 붙여넣기

무료 한도에 맞춰 AI 호출 사이에 15초 이상 간격을 두고, 한도에 걸리면 Google이 알려준 시간만큼 기다렸다가 다시 시도합니다. 자료도 1건당 4,000자로 줄여 보냅니다. 하루 3개 글이면 무료 한도 안에서 충분합니다.
참고: Google 무료 요금제는 입력한 내용이 Google 서비스 개선에 쓰일 수 있습니다.

## 선택 키

- **네이버 검색 API** (developers.naver.com, 무료): 뉴스 수집이 좋아집니다.
- **Google Programmable Search** 키와 cx: 일반 구글 검색 결과까지 수집합니다. 없으면 구글 뉴스 RSS만 씁니다.

## 원격 제어 (선택, 기본 꺼짐)

내 서버에 `server/remote_server.py` 를 올리고 실행합니다.

```bash
MYDAF_TOKEN=아무도모르는긴토큰 python3 remote_server.py --port 8787
```

프로그램 **원격 제어** 탭에서 서버 주소와 같은 토큰을 넣고 켜면, 브라우저로 `https://서버/?token=토큰` 에 접속해 시작/정지/한 편 실행/설정 변경을 할 수 있습니다.
PC가 서버에 물어보는 방식이라 PC 포트를 열 필요가 없고, 업데이트나 파일 실행 명령은 아예 없습니다. 인터넷에 열 때는 HTTPS 뒤에 두세요.

## 화면 없이 실행

```
MYDAF.exe once 전기차 보조금   # 한 편
MYDAF.exe loop                # 연속
```

## 주의

- 네이버는 자동화 도구나 AI 대량 발행을 저품질·이용 제한으로 처리할 수 있어 위 안전장치를 고정으로 넣었습니다.
- KISS 논문 본문은 유료·저작권 대상이라 초록과 서지 정보만 인용합니다.
- 네이버 에디터 화면이 바뀌면 `mydaf/naver.py` 의 `SELECTORS` 만 고치면 됩니다.
